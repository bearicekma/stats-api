はじめに

ベースURL

https://stats-api-491107.web.app

形式 / 認証

JSON（UTF-8）/ 認証不要

政府統計・金融データを一元的に取得できる中継APIです。 Power Queryから Web.Contents() で直接呼び出すことができます。 パススルー系は各機関のAPIに中継し、ストレージ系（/stats/）はGCSに蓄積済みのデータを高速返却します。

Power Query 基本パターン

① シンプルなGET（パラメータなし）

let
    url      = "https://stats-api-491107.web.app/stats/d_kanko",
    source   = Json.Document(Web.Contents(url)),
    records  = source[data],
    table    = Table.FromList(records, Splitter.SplitByNothing()),
    expanded = Table.ExpandRecordColumn(table, "Column1",
                 {"date", "都道府県名", "地域名称", "人数"})
in
    expanded

② クエリパラメータを付ける場合

let
    base   = "https://stats-api-491107.web.app",
    path   = "/boj/pass",
    query  = "?db=FM08&code=FXERD04&startDate=202401",
    source = Json.Document(Web.Contents(base & path & query))
in
    source

③ レスポンス共通構造

{
    "collection": "d_kanko",
    "count": 1234,
    "data": [ { ... }, { ... } ]   // ← この配列を Table.FromList に渡す
}

🏔 観光・労働統計

GET /stats/d_kanko 観光入込客数（都道府県・市区町村別 月次）

観光庁の月次データをGCSに蓄積済み。都道府県コード・地域コード付き。

フィールド 内容
date年月（YYYY-MM-DD）
区分pref（都道府県）/ city（市区町村）
都道府県コード2桁文字列
地域コード5桁文字列
地域名称都道府県名または市区町村名
人数観光入込客数（千人）

Power Query 例

let
    source   = Json.Document(Web.Contents("https://stats-api-491107.web.app/stats/d_kanko")),
    records  = source[data],
    table    = Table.FromList(records, Splitter.SplitByNothing()),
    expanded = Table.ExpandRecordColumn(table, "Column1",
                 {"date", "区分", "都道府県コード", "都道府県名", "地域コード", "地域名称", "人数"}),
    typed    = Table.TransformColumnTypes(expanded,
                 {{"date", type date}, {"人数", Int64.Type}})
in
    typed
GET /n_roudou/juri_sangyo 長野労働局 受理地別産業別新規求人数（月次）

長野労働局の月次PDFから抽出した産業大分類別の新規求人数。全数・うちパートを収録。

all 合計
D 建設業
E 製造業
G 情報通信
H 運輸・郵便
I 卸売・小売
J 金融・保険
K 不動産
M 宿泊・飲食
N 生活関連
O 教育・学習
P 医療・福祉
R サービス業
other その他

Power Query 例（合計行のみ）

let
    source   = Json.Document(Web.Contents("https://stats-api-491107.web.app/n_roudou/juri_sangyo")),
    records  = source[data],
    table    = Table.FromList(records, Splitter.SplitByNothing()),
    expanded = Table.ExpandRecordColumn(table, "Column1",
                 {"DATE", "産業コード", "産業分類", "新規求人数", "前月比", "前年同月比",
                  "うちパート", "うちパート前月比", "うちパート前年同月比"}),
    filtered = Table.SelectRows(expanded, each [産業コード] = "all"),
    typed    = Table.TransformColumnTypes(filtered,
                 {{"DATE", type date}, {"新規求人数", Int64.Type}})
in
    typed

🏛 政府統計 e-Stat

GET /estat/meta/{stats_data_id} 統計表のメタ情報と総件数
💡 まずメタ情報で列名・分類コード・総件数を確認してから、/estat/pass でデータを取得するのがおすすめです。

URL例

/estat/meta/0003348356

Power Query 例

let
    id     = "0003348356",
    source = Json.Document(Web.Contents("https://stats-api-491107.web.app/estat/meta/" & id))
in
    source
GET /estat/pass/{stats_data_id} 統計データのパススルー取得
パラメータ 必須 説明 例
cdTimeFrom任意開始年度コード2022000000
cdTimeTo任意終了年度コード2022999999
cdCat01任意分類1コード（メタ情報で確認）00100

URL例

/estat/pass/0003348356?cdTimeFrom=2022000000&cdTimeTo=2022999999
⚠️ 大規模データの注意： 消費者物価指数など件数の多い統計は1年単位で絞り込み、Power Queryで年ごとのクエリを作成して Table.Combine で結合してください。

🏦 日本銀行 時系列統計

日本銀行の時系列統計データ検索サイトAPIへのパススルーです。金融市場・物価・資金循環など幅広いデータを取得できます。

GET /boj/pass コードAPI — 系列コードで時系列データを取得
パラメータ 必須 説明 例
db必須DB名（下表参照）FM08
code必須系列コード（カンマ区切りで複数可、同一期種のみ）FXERD04
startDate任意開始期（月次・日次ともYYYYMM形式）202401
endDate任意終了期（同上）202412
💡 系列コードの調べ方： /boj/meta?db=DB名 でメタ情報を取得し、SERIES_CODE列を参照してください。

URL例（USD/JPY 日次）

/boj/pass?db=FM08&code=FXERD04&startDate=202401

URL例（USD/JPY 月次平均）

/boj/pass?db=FM08&code=FXERM07&startDate=202401

Power Query 例

let
    url    = "https://stats-api-491107.web.app/boj/pass?db=FM08&code=FXERD04&startDate=202401",
    source = Json.Document(Web.Contents(url)),
    series = source[RESULTSET]{0},
    dates  = series[VALUES][SURVEY_DATES],
    values = series[VALUES][VALUES],
    table  = Table.FromColumns({dates, values}, {"日付", "値"}),
    typed  = Table.TransformColumnTypes(table, {{"値", type number}})
in
    typed
GET /boj/layer 階層API — 階層情報でデータを一括取得
パラメータ 必須 説明 例
db必須DB名BP01
layer必須階層情報（カンマ区切り。* でワイルドカード）1,1,1
frequency必須CY（暦年）/ FY（年度）/ Q（四半期）/ M（月次）/ D（日次）M
startDate任意開始期202504
endDate任意終了期202509

URL例

/boj/layer?db=BP01&frequency=M&startDate=202504&endDate=202509&layer=1,1,1
GET /boj/meta メタデータAPI — 系列コード一覧・収録期間を取得

URL例

/boj/meta?db=FM08
